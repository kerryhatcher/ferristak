# Archived primary sources

Retrieved 2026-10-21 for the [TAK research set](../README.md). Files retain their upstream paths and original contents. The collection is selective; it is not a complete clone or complete SDK.

- `atak-civ/takproto`: official protocol text and client protobuf schemas.
- `atak-civ/takcot`: MITRE public-release and TAK-specific XML schemas.
- `atak-civ/commoncommo`: selected client codec, stream, enrollment and package-transfer implementations.
- `Server`: selected server controllers, servlets, grouping code, schemas, configuration and generated OpenAPI.
- [manifest.json](manifest.json): exact source URLs, pinned repository revisions, sizes and SHA-256 for all downloaded references, including PDFs stored in `../pdfs`.

Source files and schemas have their own copyright/license notices. Repository licenses are preserved alongside the relevant source trees. These files are research references and are not automatically dependencies of Ferristak.
